# M15 实验结果：观察动作后的意图与设施预测

## 一句话结论

这次实验**没有完整验证原 motivation**。Bob 看到 Alice 的第一个实际动作以后，仅凭公开状态和动作就几乎能够判断她的意图与设施；旧印象与新印象在相同事件上的预测基本一样。在线运行中，新印象组的表面准确率更高，但团队得分反而更低，因此不能得到“更新印象会改善合作”的结论。

## 实验口径

- 训练 Bob：seeds 6001–6024；
- 独立测试：seeds 7001–7016；
- 每局 700 tick；
- 只在 Alice 的宏观意图改变时记录一次；
- Bob 在 Alice 执行新意图的第一个 primitive action 后预测；
- 输入：公开的动作前状态、Alice 第一个动作、公开的动作后状态和 impression；
- 输出：八类意图和具体设施 ID，不输出坐标或路线；
- 正式训练事件 7,769 个；
- 固定测试事件 5,203 个，其中 pre 2,290 个、post 2,913 个。

## 1. 固定轨迹：只切换印象

这是判断“印象本身是否改变预测”的最干净比较，因为三个条件看到完全相同的 post-Alice 事件。

| 条件 | 意图准确率 | 设施准确率 | 两项同时正确 |
|---|---:|---:|---:|
| post + 旧印象 | 99.97% | 99.93% | 99.93% |
| post + 新印象 | 99.97% | 99.93% | 99.93% |
| post + 无印象 | 99.97% | 99.93% | 99.93% |

三个结果完全相同。这说明在当前地图和观察输入下，Alice 的状态与第一个动作已经几乎把答案直接表现出来，模型没有实际依赖 impression。

## 2. 在线配合：预测会改变 Bob 后续行为

下表是 16 个测试 seed 的每局均值。

| 条件 | 意图准确率 | 设施准确率 | 平均送汤 | 平均总分 |
|---|---:|---:|---:|---:|
| pre Alice + 正确旧印象 | 95.83% | 95.63% | 1.19 | 23.75 |
| post Alice + 旧印象 | 95.67% | 90.51% | 20.44 | 408.75 |
| post Alice + 新印象 | 98.17% | 94.43% | 18.94 | 378.75 |
| post Alice + 无印象 | 95.85% | 90.50% | 20.56 | 411.25 |

核心配对比较“post + 新印象”减去“post + 旧印象”：

- 意图准确率：+2.49 个百分点，95% CI `[+1.97, +2.94]`；15/16 seed 提高，1 个持平；
- 设施准确率：+3.92 个百分点，95% CI `[+3.17, +4.53]`；15/16 seed 提高，1 个持平；
- 平均送汤：-1.50 碗，95% CI `[-1.875, -1.0]`；15/16 seed 下降，1 个持平；
- 平均总分：-30 分，95% CI `[-37.5, -20]`。

因此，在线实验出现了“预测更准，但配合得分更差”的结果，不能用来支持完整证据链。

## 3. 为什么在线准确率提高，固定轨迹却没有差别

在线条件中，Bob 的预测会改变自己的动作，进而改变之后的厨房状态，所以旧印象组和新印象组最终经历的事件并不相同。直接比较两组在线准确率，会同时混入“印象变化”和“轨迹变化”。

为此，正式日志对每一个在线事件额外做了反事实检查：保持该事件完全不变，只把 impression 从 pre 切成 post。

- 在 post + 旧印象轨迹上，只有约 0.94% 的事件改变了意图输出，约 3.14% 改变了设施输出；
- 在 post + 新印象轨迹上，只有约 1.06% 的事件改变了意图输出，约 3.35% 改变了设施输出。

所以在线准确率的较大差异，主要来自两组后续轨迹不同，不能全部解释为印象更新直接改善了判断。

## 4. 为什么更准确反而少得分

新印象组平均每局进行 31.88 次预测路线让行，旧印象组为 16.88 次；但两组尝试发生的移动冲突完全相同，平均都是 43.94 次。

也就是说，更准确的设施判断使 Bob 更频繁地为 Alice 让路，却没有减少已经统计到的通行冲突，反而浪费了行动时间。这说明当前手写的“预测目标后主动避让”规则过于保守，预测正确不等于下游使用方式正确。

该规则已经按照审核要求修正为“距离自己目标更远的一方让路”，以上仍是修正后的结果，不是早期无条件让路版本的数据。

## 5. 当前结果能说明什么

可以说明：

1. “动作后预测”的数据和在线链路已经真正跑通；
2. Bob 的输入确实包含 Alice 已执行的动作，而不是只根据厨房状态猜；
3. 意图和设施预测都能训练到很高准确率；
4. 更准确的伙伴理解如果接到不合适的配合规则上，不一定提高团队得分。

不能说明：

1. 旧印象会稳定导致 Bob 误解成长后的 Alice；
2. 更新印象会稳定提高团队得分；
3. 当前 M15 已验证完整 motivation。

## 6. 暴露出的设计问题

- 当前厨房的行为太容易识别：看到状态、第一步动作和动作结果后，几乎不需要 impression；
- pre Alice 与固定 Bob 控制器的配合很差，平均只有 1.19 碗，说明该基线控制器仍不够通用；
- 设施预测目前主要触发让路，而没有带来可测的冲突减少；
- 在线准确率会受到轨迹分叉影响，今后必须同时报告固定轨迹反事实结果。
