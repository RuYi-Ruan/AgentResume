# M14 数据来源与计算说明

更新日期：2026-09-11

这份文档解释以下三个数字是怎样得到的：

1. Bob 使用旧印象时，对成长后 Alice 的意图判断准确率为 **66.49%**；
2. Bob 使用新印象时，准确率为 **100%**；
3. 在“相同局面下成长前后意图不同”的关键事件中，旧印象为 **23.08%**，新印象为 **100%**。

完整汇总保存在 `data/m14_checkpoint_impression_results.json`，逐事件明细保存在 `data/m14_event_predictions.csv`。

## 1. 这里的 Alice 和 Bob 分别是什么

Alice 有两个来自同一次学习过程的版本：

- `pre`：先通过行为克隆学会基本做饭，独立测试中每局平均完成 15 碗；
- `post`：在 pre 的基础上继续进行 30 次 PPO 更新，每局平均完成 24.625 碗。

因此，pre/post 不是人工切换两套状态机规则，而是同一个神经网络训练前后的两个 checkpoint。

这里的 Bob 暂时不是会在厨房里行动的完整智能体，而是一个“观察当前局面并猜测 Alice 宏观意图”的 MLP。它需要从八种意图中选择一种：

```text
FETCH / PLACE / COOK_START / GET_DISH /
PICKUP / DELIVER / PRE / HOLD
```

Bob 的输入包括当前厨房状态，以及一个两维的 Alice 印象：

```text
旧印象（stale） = [1, 0]，认为 Alice 是 pre
新印象（updated）= [0, 1]，认为 Alice 是 post
```

## 2. 数据怎样划分

训练 Bob 意图模型时使用：

- seeds 4001–4024；
- pre 和 post Alice 各运行一次；
- 共得到 8,342 个真实决策事件。

正式测试使用完全不同的 seeds 5001–5016：

- pre Alice：2,475 个决策事件；
- post Alice：3,089 个决策事件。

这里的一个“事件”是 Alice 真正选出一个新宏观意图的时刻，不是把同一意图持续执行的每个 tick 重复计算。

## 3. 66.49% 和 100% 怎样计算

实验固定 post Alice 的 3,089 个测试事件。每个事件的厨房状态、Alice 行为和真实意图都完全不变，只替换 Bob 输入中的 impression：

| 条件 | 正确数 | 总事件数 | 准确率 |
|---|---:|---:|---:|
| 旧印象 stale `[1,0]` | 2,054 | 3,089 | **66.49%** |
| 新印象 updated `[0,1]` | 3,089 | 3,089 | **100%** |
| 不输入印象 state-only | 3,077 | 3,089 | 99.61% |

计算公式就是：

```text
stale accuracy   = 2054 / 3089 = 0.664940... = 66.49%
updated accuracy = 3089 / 3089 = 1.000000... = 100%
```

这里不能简单解释为“新印象让所有普通场景都变得更容易”。state-only 在全部事件上已经达到 99.61%，说明绝大部分日常局面仅看当前状态就能猜对。印象真正有价值的地方是下一节的重解释事件。

## 4. 什么是“重解释事件”

我们用以下信息定义一个可观察局面：

- Alice 的位置和手持物；
- 伙伴的位置和手持物；
- 两口锅的状态。

在训练轨迹中，如果 pre Alice 和 post Alice 面对同一种局面时，最常选择的意图不同，就把这种局面标记为“需要重解释的局面”。然后只在独立的 post 测试轨迹中寻找这些局面。

最终找到 39 个 post 测试事件：

| 条件 | 正确数 | 关键事件数 | 准确率 |
|---|---:|---:|---:|
| 旧印象 stale | 9 | 39 | **23.08%** |
| 新印象 updated | 39 | 39 | **100%** |
| 不输入印象 state-only | 28 | 39 | 71.79% |

```text
stale reinterpretation accuracy   = 9 / 39  = 23.08%
updated reinterpretation accuracy = 39 / 39 = 100%
```

按测试 seed 分别计算 updated−stale，再进行配对 bootstrap：

- 16/16 个 seed 都是新印象更准确；
- 每 seed 平均提升 73.96 个百分点；
- 95% 置信区间为 `[61.46, 87.50]` 个百分点。

## 5. 几个具体例子

### 例 1：一口锅在煮，另一口锅空着

```text
Alice=(2,1)，伙伴=(3,2)，两人空手
锅状态：左锅 cooking，右锅 empty
成长前常见意图：HOLD
成长后真实意图：FETCH
旧印象预测：HOLD（错误）
新印象预测：FETCH（正确）
```

直观含义是：过去的 Alice 倾向于等当前这锅完成，成长后的 Alice 会利用等待时间去取洋葱，为另一口锅补料。

### 例 2：左锅一份料，右锅正在煮

```text
Alice=(2,1)，伙伴=(3,2) 且拿着盘子
锅状态：左锅 items1，右锅 cooking
成长前常见意图：HOLD
成长后真实意图：FETCH
旧印象预测：HOLD（错误）
新印象预测：FETCH（正确）
```

### 例 3：左锅已放满三份料

```text
Alice=(2,1) 空手，伙伴=(5,1) 且拿着洋葱
锅状态：左锅 items3，右锅 empty
成长前常见意图：HOLD
成长后真实意图：COOK_START
旧印象预测：HOLD（错误）
新印象预测：COOK_START（正确）
```

## 7. 应当怎样理解这些结果

目前可以说：

> 同一个 Alice 通过 PPO 训练显著提高能力后，旧的 pre belief 会让条件意图模型用过去的行为模式解释她，从而在成长后行为上产生系统性误判；正确的 post belief 能恢复判断，尤其是在成长前后会作出不同选择的关键局面。

目前还不能说：

- Bob 已经能自动发现 Alice 成长了；updated belief 目前由实验直接提供；
- 所有普通局面都必须依赖印象；state-only 在全事件上已经很强；
- 100% 会推广到新地图、新伙伴或有噪声的复杂环境；当前策略和轨迹仍较规则；
- 意图猜得更准一定会提高团队分数；Bob 尚未根据预测真正改变自己的行动。

下一步是让 Bob 观察 Alice 前 `P` 步行为，自己判断应使用 pre 还是 post impression，并测试 `P=5/10/20/40/80` 时多久能够完成印象更新。
