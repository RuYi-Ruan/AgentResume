角色

Alice 负责"变强"，Bob 负责"搞懂她"

Alice · 被研究的那个

182 维状态→ 128→ 128→ 8 种意图

每次输出一个高层意图（拿料 / 下锅 / 点火 / 拿盘 / 取汤 / 送餐 / 等锅 / 原地）。
走过去、按按钮由"执行器"代劳——那是肌肉，不是决策。

Bob · 搭档兼读心者

供料/ 做服务+ 猜 Alice 想干嘛

一方面和 Alice 一起干活；另一方面，看到她的第一步动作后，要判断她是"想等锅"还是"想拿料"。

为什么只猜这两种？题目是有意挑出的岔路口：画面一样、第一步也一样，她要么守着锅（PRE），要么转身去拿洋葱（FETCH）。 其余 6 种意图的场面，要么第一步动作就不同，要么可见线索已经露了底，凑不出这种严格配对。
关键：Alice 的真实意图不会喂给 Bob —— 他只能靠画面、动作和手里的印象。 这三样东西的差别，就是实验唯一在变的量。
