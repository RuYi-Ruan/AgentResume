# Gate 1：可观察、定向 ETM 复验

目标：在 Gate 0 的连续伙伴学习轨迹上，检验六条定向 ETM 能否跟踪伙伴行为变化。

流程：

1. 三名 MLP 保持初始策略不变，动态与冻结 ETM 接收完全相同的校准轨迹并进行等量训练；
2. 启动 Gate 0 的连续学习过程，不加载或切换策略 checkpoint；
3. 冻结 ETM 停止参数和历史状态更新，动态 ETM 继续根据可观察轨迹更新；
4. 两种 ETM始终在完全相同的伙伴轨迹上预测下一时间窗的可观察交互事件。

每条 `观察者→伙伴` 关系使用独立网络和独立历史状态。ETM 输入仅包含局部可见的相对位置、持物和原子动作，不接收伙伴角色、MLP 参数、训练进度或中心教师标签。

该实验只验证伙伴认知，不把 ETM 接入决策。
