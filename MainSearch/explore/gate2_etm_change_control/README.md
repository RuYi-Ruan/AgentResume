# Gate 2：伙伴变化与训练量对照

每个 ETM 在一局内都正常读取新观察并更新 GRU 隐状态；跨局差别只在于参数是否继续训练。这样不会把“冻结长期认知”误写成“不再读取当前证据”。

对照条件：

- `evolving_stale_budget`：与动态 ETM 接受相同数量的更新，但始终用初始静态伙伴轨迹训练；
- `static_dynamic` / `static_frozen`：伙伴始终保持初始策略，用于测量单纯增加训练次数的收益。

核心比较是：变化伙伴下，最新轨迹训练是否优于等训练量的旧分布训练；静态伙伴下，持续训练是否仍产生同等大的优势。

`--hidden-mode persistent` 仅用于复现旧版混淆诊断，不作为 Gate 2 结论。
