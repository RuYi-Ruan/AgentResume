# 可观察 ETM 决策闭环门槛

目标：检验不使用隐藏角色标签的 ETM，能否通过学习型协调网络提高三人 Overcooked 出汤数。

三个配对条件：

- `no_etm`：协调网络看不到伙伴模型；
- `frozen_etm`：ETM 在第 60 局后冻结；
- `dynamic_etm`：ETM 持续根据可观察轨迹更新。

三名智能体均维护两条定向认知状态，并用各自的协调 MLP 读取自己的角色提议、位置和两名伙伴的事件分布。协调 MLP 不使用手写角色匹配。

开发阶段比较两种接口：

- `frozen`：第 60 局后协调 MLP 也冻结，用于隔离 ETM 更新；
- `continuous`：三种条件的协调 MLP 都持续使用同等监督在线更新，检验 ETM 与决策接口共同适应。

这是探索阶段门槛，低层动作仍由规则执行器完成。
