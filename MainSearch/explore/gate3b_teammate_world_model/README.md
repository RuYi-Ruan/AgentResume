# Gate 3b：伙伴条件动作结果模型

复用 Gate 3 修正版的 540 个评估局面。每个局面在观察 30 步后，分别实际执行决策者的三种候选分工，记录 30 步后的局部可见状态、30 步出汤数和整局出汤数。

输入仅包含决策者当下的局部可见状态、候选分工，以及两条定向 ETM 对伙伴分工的估计。训练集为第 60–240 局检查点，验证集为第 300 局，测试集为第 360 局。三种 ETM 估计共同训练同一个结果模型，测试时比较动态、冻结、旧分布认知与保持原分工。

这是短步状态转移加结果预测门槛。低层仍是规则执行器，且它不等于已经实现完整多步世界模型规划。

结果：模型本身能找到全部 18 个有益补位机会，但去掉 ETM 输入后表现不降，故 ETM 必要性门槛未通过。详见 `RESULTS.md`。
