## 0. 场景与角色

- 环境：SMAX `2s3z`（5 盟友：agent0–1 = Stalker，agent2–4 = Zealot；敌人脚本策略）。

- 伙伴候选参数来自既有 run `results/smax_2s3z_indep_1250x64x64/` 的存档：

## 1. 画像 z（三维，按身份分别输入，不平均）

维度定义（每名伙伴、每个候选策略各算一次）：
1. `damage_per_len` = 该身份造成的总伤害 / 该局局长；
2. `alive_frac` = 该身份存活步数 / 该局局长；
3. `focus_share` = 该身份的**有效攻击**中，"同一时间步内 ≥1 名其他盟友也攻击了同一目标"的比例；
   有效攻击 = 该步该身份对某敌人造成伤害的攻击；若无有效攻击则记 0（不产生 NaN）。

- **测量口径**：标准参考队伍 + **固定测量局面**（与训练局、测试局都不重叠；见 §3）。
- **归一化**：用**校准集 = 这 12 个候选策略的画像**算 `mean/std`（std 加 `1e-8` 防零除），**冻结**；
  `z = (profile - mean) / std`。
- **placeholder 臂输入全 0**（因为已中心化 ⇒ "全零"与"固定均值"统一）。
- **z 向量** = 按身份顺序 `[1, 2, 3, 4]` 拼接，每个身份 3 维 ⇒ **12 维**；**不得**平均成团队画像。

## 2. 伙伴序列与随机流（两臂必须逐局一致）

- **禁止**假设"同一种子 ⇒ 同一伙伴序列"：两臂局长可能不同。
- 伙伴组合与重置种子必须由 **(环境槽位 slot, 该槽位的局序号 episode_index)** 确定性生成，且**与动作采样随机流分离**：
  - `partner_stage(slot, ep_index, partner_identity)`：由 `PRNGKey(hash(PARTNER_SEED, slot, ep_index, identity))` 决定该局该伙伴取 `{u50,u600,u1250}` 中哪个；
  - `env_reset_key(slot, ep_index)`：由 `PRNGKey(hash(RESET_SEED, slot, ep_index))` 决定（同样只依赖 slot 与该槽位已完成局数）；
  - 动作采样用**独立的 rng 链**（每 update 从另一个 seed 派生）。
- 因此：即使两臂某槽位局长不同，**同一 (slot, ep_index) 的伙伴组合与初始局面在两臂中完全相同**。
  必须用短测证明这一点（见 §5 检查 2）。

## 3. 三套局面严格分离

| 用途 | seed 集 | 说明 |
| --- | --- | --- |
| 画像测量（§1） | A = `[2234,2235,2236,2237,2238]` | 只用于算 12 个候选的画像与归一化 |
| 训练 | B = 训练局种子流（`TRAIN_SEED`） | 与 A、C 不重叠 |
| 测试（§4） | C = `[3234,3235,3236,3237]`（4 个新局面） | 只用于门槛评测 |

## 4. 门槛评测（主/次指标）

- 覆盖**全部 81 种伙伴阶段组合**（3^4）× **4 个新测试局面** = **324 局/臂**。
- **配对单位 = (伙伴阶段组合, 测试局面)**；两臂用**同一批 324 个 (组合, 局面)**。
- **主指标 = 平均团队回报**；**胜局数仅作辅助**。
- 不确定性：对**这 324 个配对**做 bootstrap；报告中必须写明"这是对该固定局面集的不确定性，不是对 SMAX 总体的抽样"。
- 这些局**不是训练种子的复验**，不得当作独立样本量或复验证据。

## 5. 画像交换检查（匹配状态，固定 GRU 隐状态）

- 在**同一批匹配状态**（同一批局面 + 同一批轨迹位置）上，比较：
  (a) 正确画像 z；(b) **同一身份的过时画像**（例如把该伙伴的 `u1250` 画像换成其 `u50` 画像，其余 3 名伙伴不变）。
- **必须固定 GRU 隐状态**：两次前向用**相同的 hstate**（在交换点注入同一 hstate），否则差异无法归因。
  短测需断言两次调用的 hstate 逐叶相等。
- 输出：动作分布 TV / JS、argmax 切换率。
- **解释约束**：动作分布变化**只说明输入影响决策，不说明这种变化有益**；写进输出说明。

## 6. 最终解释约束（写进所有输出）

- 即使**画像可分、接口正常但没有收益**，也只能写"**本配置未发现收益**"，**不能**判定"伙伴信息无价值"。
- 不做因果归因；不把局面执行次数当独立样本量；`±sd(seed)` 不是置信区间、不是判据。
