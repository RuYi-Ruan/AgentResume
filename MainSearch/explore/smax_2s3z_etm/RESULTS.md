# SMAX `2s3z` 固定身份独立训练：单种子 5.12M 步结果（2026-09-27）

> 目的：回答"**独立身份也能学起来，并留下可检验的成长轨迹**"。**不是** ETM / Oracle 对照，**不是** P2 主实验结论。
> 产物：`results/smax_2s3z_indep_1250x64x64/`（`run.json` + 26 个 checkpoint：初始 `00000000` 与每 50 updates 一个，末段 `000001250`）。

## 1. 运行配置与事实

| 项 | 值 |
| --- | --- |
| 规模 | 1250 updates × 64 envs × 64 rollout = **5,120,000 环境步**，单种子（seed 0） |
| 架构 | 官方 GRU-IPPO 配方（同网络/同 PPO-GAE/同环境/同胜局判据），唯一改动：**5 个身份各自一套参数 + 各自 optimizer + 各自 GRU 隐状态**，各自局部 critic（**无共享 CTDE critic**）|
| 学习率 | 4e-3，**官方分段退火**（更新内恒定、每 update 降一档），1250 updates 处归零 |
| 评测 | **固定 5 个种子 × 每种子 4 局 = 20 个固定局面**，每段重放同一批局面 ⇒ 段间为**配对**比较 |
| 耗时 | **89.0 分钟**（wall），吞吐 646 → ~1,150 步/秒（前两段受其他任务占 CPU 影响）|
| 异常 | 无：无非有限数值、lr 单调下降、26 个 checkpoint 全部写盘 |

## 2. 学习曲线（主轴 = 环境步数；辅以耗时）

固定 20 局评测的胜局数（同一批局面每段重放）：

| 环境步数 | 0.20M | 0.82M | 1.64M | 2.46M | 3.28M | 4.10M | 4.71M | 4.92M | **5.12M** |
| 胜局 /20 | 0 | 5 | 5 | 3 | 9 | 9 | 12 | **13** | 12 |
| 评测回报 | 0.62 | 1.09 | 1.14 | 1.00 | 1.36 | 1.36 | 1.54 | 1.62 | **1.54** |

完整序列（每 50 updates 一段，25 段）：胜局 `0,0,1,5,4,6,6,5,3,5,8,3,9,3,10,9,7,5,7,9,9,13,12,13,12`；
回报 `0.62,0.73,0.79,1.09,1.01,1.17,1.19,1.14,1.04,1.08,1.31,1.00,1.36,1.03,1.42,1.36,1.22,1.11,1.23,1.36,1.33,1.59,1.54,1.62,1.54`。

- 观察量陈述：胜局与回报**波动上行**（0/20 → 12–13/20；回报 0.62 → ~1.5）。
- **不作因果归因**：胜局增加与学习率退火在时间上同时发生，**不代表收益由退火造成**（无固定学习率对照臂）。
- **不作 update 对齐**：本机每 update 4,096 步，官方 16,384 步，参数共享方式也不同 ⇒ 只按**环境步数**比较。

## 4. 这轮**证明**了什么 / **没有**证明什么

**证明了（本单次运行范围内）**：
1. 独立身份训练**能学起来**：在固定参考队伍下，5 个身份的主比较（`u50 → u1250`）在**伤害造成上整体改善**
   （+46.6～+88.9，各自身份的五个种子组方向全为正）且击杀、存活步总体上升，**但不同指标存在波动与取舍**
   （存活步/击杀在中期→后期有下降的身份，见 §3.2）；
2. 训练器端到端可用：初始状态 + 每 50 updates 存档、逐段固定评测、无异常结束。

**没有证明（不得外推）**：
1. **这不是 P2 / 持续学习主实验**：诊断把 4 名队友冻结在末段 ⇒ 移除了同时学习、共同适配、非平稳性；
2. 因此 `late−early` 差值**同时包含**"该身份自身能力变化"与"它与训练期伙伴的配合适应性"，**不能整体解释为个人能力提升**
   （且末段策略是在伙伴不断变化时学到的，被拿去与冻结队伍配合时可能存在 mismatch，甚至低估）；
3. **稳定性未验证**：单种子、单次运行；
4. **不做因果归因**：不推断收益来自学习率退火；
5. **样本量口径**：训练评测 25 段 × 20 局面 = 500 次**局面执行**、诊断 20 配置 × 20 局面 = 400 次**局面执行**，
   都是同一批局面的重复执行，**不是独立样本**；`±sd(seed)` 只描述种子组间差异，不是置信区间、不是判据。
