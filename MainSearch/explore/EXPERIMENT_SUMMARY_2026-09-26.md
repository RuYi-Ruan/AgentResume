# 本轮实验总梳理（2026-09-24 → 09-26）

用途：把"ETM 主实验该用哪个 benchmark"这一轮跑过的所有实验、判定与边界整理清楚，供下一步决策。所有数字都对应本机实测，原始记录在各自 `results/` 目录。**本文不是正式结论，正式结论需要多种子与更多评测局数。**

## 一、要找的东西（判据）

主实验环境必须同时满足：

1. **≥3 个固定身份智能体**，各自学习、输出**低层原子动作**（不允许规则执行器、不允许靠切换 checkpoint 模拟伙伴成长）。
2. **伙伴能力在协作中真正演化**（行为随训练持续变化，而不是早期冻结）。
3. **本机可负担多种子**（CPU-only，JAX 向量化；经验线：单次运行 ≲ 1 小时、可重复 5+ 次）。
4. **伙伴行为可观察且影响结果**——即"读懂伙伴下一步做什么"能改变最优行动（这是 ETM 有意义的前提）。
5. ETM 三段门槛：**信息门槛**（在线认知 > 冻结认知 / 等量历史）→ **闭环门槛**（把认知接进策略后协作指标提升）→ 世界模型（可选）。

| **ETM 信息门槛** | 5 个训练阶段（0.41M–16.79M）各 96 局轨迹，12 条有向对，只统计可见步 | 常数先验 0.357、**冻结 0.227**、**在线 0.409**、累积全阶段 0.408、等量 8 帧历史 0.376 | ✅ 在线 > 冻结（+18.2 点）、历史不能替代、视野含伙伴信息（+5.2 点） |
| 信息门槛第一版（失败） | 不限可见步 | 常数先验 0.415 > 所有学习模型（最高 0.381） | 设计硬伤，已修并保留 |
| 闭环门槛 `sr=1` | 三臂各 8.19M 步 | 无认知 2.81 / 冻结 2.88 / 在线 3.34 → 在线−无认知 **+0.53**（≈1.2 SE） | ⚠ 不决定性 |
| 闭环门槛 `sr=2` | 三臂各 8.19M 步（可见度 17%） | 无认知 **4.38** / 冻结 4.03 / 在线（拼分布）3.53 → **−0.85** | ❌ 未通过且为负 |
| 接口诊断 `online_visible` | 只拼"伙伴在视野内"的预测 | **3.44**（−0.94） | ❌ 与拼分布相同 |
| 接口诊断 `online_onehot` | 拼 argmax 独热而非 5 维分布 | **4.19**（−0.19，进入 10–25% 运行波动内） | ⚠ 基本持平，最接近有用 |
| 接口诊断 `aux_loss` | 预测不进观测、改作共享主干的辅助损失 | **3.81**（−0.56） | ❌ 辅助目标无正迁移 |

**接口诊断结论（2026-09-26 完成）**：`sr=2` 下六条臂（对照、冻结、在线拼分布、只拼可见、拼独热、辅助损失）**没有任何一条超过无认知对照**；最好的一条（拼独热）为 −0.19，落在运行波动内。"拼分布"换成"拼独热"能把损失从 −0.84 收到 −0.19，说明接口噪声确实是部分原因，但**限制可见伙伴、改成辅助损失都没有改善**。

关键横向发现：**提高伙伴可观察性把无认知对照臂从 2.81 抬到 4.38（+1.57），但收益全进了策略本身，没有一条 ETM 接口受益**；把预测压成"独热"能把损失从 −0.85 收到 −0.19，说明"拼分布"这个接口本身有噪声代价。

## 四、现在能确定的三件事

1. **研究动机与信息价值成立**：伙伴行为确实随训练演化（TV 0.44–0.55），且在线队友模型的预测显著优于冻结模型（0.409 vs 0.227），等量历史不能替代。
2. **闭环收益在本机预算内未能复现**：两种可观察性（7.1% / 17.0%）× 三种接口（拼分布 / 只拼可见 / 拼独热）都未超过无认知对照 1 碗；最好的一条（独热）为 −0.19（波动内）。
3. **环境约束是硬约束**：能学得会的环境（RWARE）伙伴动作语义弱；语义强的环境（Overcooked 官方配方、Melting Pot）本机要么学不动、要么装不上、要么 8 小时/种子。

## 五、思路整理：三条路径

**路径 A：继续在 RWARE 上做接口/任务侧改造（成本 3–6 小时/轮）**
- 可做：等 `aux_loss` 结果；若它 ≥ 对照 +1 碗 → 主环境定 RWARE，补种子与 64–128 局评测。
- 若 `aux_loss` 也持平/为负：把**任务**改成"伙伴动作影响结果"更强的变体——例如让库房出现"共搬货架"（需两机器人同时接触）或把交付改成"必须由另一个机器人完成最后一步"，这样知道伙伴下一步做什么才有价值。这仍然是 RWARE，但改了规则，需要新的规则校验与学习门槛（约 2–4 小时实现 + 1 小时门槛）。
- 风险：改动后的任务可能更难学；且"自定义任务"在论文里需要额外论证其代表性。

**路径 B：换到 SMAX + 能学的学习器（成本 4–8 小时）**
- 本机唯一同时具备"伙伴全可见 + 动作语义强 + 可负担"的环境；缺的是能学的算法。
- 两条实现路线：① 给现有 MLP 策略补 GRU（官方 SMAX IPPO 配方，含 BPTT，约 2–4 小时实现），先过 1000 万步胜率门槛；② 把 JaxMARL 的 QMIX/VDN 改成非共享（每智能体独立参数，符合项目规则），本项目历史上 QMIX 在这类任务上 30–50 万步出现过 100/100 胜（伴随跳变，需更多评测局确认）。
- 风险：① 需要动机器代码较多；② QMIX 胜率跳变会让"伙伴能力演化"的测量变脏。

**路径 C：收束为分析型结论（成本 1–2 天写作，不再跑大实验）**
- 已有素材足够：动机/信息价值证据（在线 vs 冻结 vs 历史）、六环境可负担性对照（含每步成本与 20M 步耗时）、闭环在两种可观察性与三种接口下的负结果、以及"瓶颈在伙伴动作语义而非认知质量"的诊断。
- 需要明确写出的前提：本机为 CPU-only；要观察到 ETM 的闭环收益，需要 (i) 伙伴动作可观察、(ii) 伙伴动作影响结果、(iii) 认知质量相对单帧/先验有足够优势、(iv) 足够算力把任务训练到协作成熟期。

**我的建议**：等 `aux_loss` 跑完 → 若它明显为正，走 A 的"补种子"；若为负，优先考虑 **B 的第②条（QMIX 非共享）**，因为它是唯一可能同时满足全部四条判据的路径；若 B 的实现成本超预期或胜率仍跳变，则走 C，把这一轮的全部证据写成研究记录。

## 七、失败与负结果清单（不静默）

- OvercookedV2：官方管线 1M 步无学习曲线；小前馈 20M 步 0 出汤 0 形状奖励。
- SMAX：离规格 LR 运行（归档）；官方超参 10M 步 0 胜。
- RWARE：ETM 信息门槛第一版设计缺陷（不限可见步时先验反而最高）；闭环 sr=1 不决定性、sr=2 为负；接口 visible/onehot 未达 +1 碗；sr=3 因过慢取消（归档）。
- 环境侧：Mava 在 Windows 全量安装失败（`pytinyrenderer` 需 MSVC）；Melting Pot 无 Windows 轮子；`sr=3` 三臂需约 7 小时不可行。
- 工程缺陷：检查点文件名冲突导致一个 8M 运行的中间检查点被覆盖（曲线数据完好）；训练局数统计口径错误（已修）。
