# 三人 OvercookedV2 可行性门槛（探索实验）

目标：检查换用更难的 OvercookedV2 后，能否建立「三名固定身份伙伴持续学习 → 伙伴认知有用 → 动态 ETM 改善协作」这条链。此目录的探索结果不算正式主实验。

## A. 环境与成本（本轮先做）

- 从 JaxMARL 官方 `grounded_coord_ring` 地图增加第三名起始智能体；其余地图符号与菜谱不改。明确称为**三人改编地图**，不冒充官方双人 benchmark 结果。
- 3 个种子各跑一局 200 步的随机合法动作，检查每局都有 3 份观察、动作、奖励及全局终止；记录编译及交互耗时、异常。随机策略得分不用于判断任务可学性。
- 通过条件：所有运行完成且 API 稳定。失败则停止，不投入训练。

## B. 无 ETM 的学习基线（A 通过后）

- 使用原始低层动作，不使用手写分工/规则执行器。先测短程训练吞吐，再确定可承担的训练步数，不直接启动官方 3000 万步配置。
- 三名固定身份 actor 分开更新；训练可用集中 critic，执行时各自仅用合法局部观察。记录每个智能体随训练的性能轨迹，不能用切换 checkpoint 假装在线能力提升。
- 每 5 万环境步冻结评测，在事先固定的 100 个起点上报告每局出汤、奖励与完成率；至少 3 个训练种子。若预算内无可靠进步，标记为训练/环境门槛未过，不能推断 ETM 无效。

## C. ETM 信息价值（B 通过后）

- 保留三名固定身份，六条有方向的观察者→伙伴模型；只用观察者在执行时可见的轨迹更新，不泄漏伙伴动作、角色标签或环境全局状态。
- 官方默认观察把其他智能体的特征相加，抹掉了 B/C 身份；正式接 ETM 前须给所有对照组使用同一套保留队友身份的局部观察编码，且不能增加视野或暴露隐藏状态。
- 预先固定训练/验证/测试切分，比较当前局部观察、等量历史但冻结 ETM、在线 ETM 在伙伴下一步动作/意图预测上的增益，并检查同一场景是否确实需要伙伴历史才能区分。

## D. 闭环协作（C 通过后）

- 固定基础 actor、训练预算、地图和评测起点，配对比较无 ETM、冻结 ETM、在线 ETM；每个智能体都使用自己的两条定向 ETM。主指标是每局出汤数，同时报告伙伴预测准确率与冲突/等待等机制指标。
- 只有认知增益能够转化为稳定协作收益，才进入世界模型与正式多种子实验；否则先诊断策略接口或换 benchmark。
