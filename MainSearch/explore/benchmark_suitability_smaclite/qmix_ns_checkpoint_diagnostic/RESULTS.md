# 非共享 QMIX 检查点诊断（开发实验）

- 数据来源：`qmix_ns_300k_seed0` 一次从零连续训练；选取 10、16、20、22、24、26、28、30 万步附近的 8 个检查点，每个在固定种子 0–49 上独立复放 50 局，共 **400 局**。所有检查点的胜局数及平均回报均与原在线评测吻合。检查点只用于训练后离线诊断，不在一局内切换。
- 团队胜局数依次为 **0、0、0、50、0、32、0、50 / 50 局**。因此策略能获胜，但没有稳定的渐进胜率曲线。
- 在各检查点轨迹合并出的同一批局部观测上比较策略动作：28→30 万步时五人的动作改变比例分别为 **27.94%、39.31%、36.94%、12.63%、16.00%**，基数为每人最多 1,600 个存活状态探针。这说明五套策略变化不同步，不说明各自能力单调提升。
- 30 万步检查点中，2 号智能体在 50 局共 850 个存活决策上 **100% 移动、0 次攻击**，50 局最终均死亡，但团队 50/50 获胜。可能是诱敌/牺牲分工，也可能是策略缺陷；仅凭动作统计不能判定。
- 无泄漏的局内历史预测诊断：输入仅为观察者自己的当前局部观测，或再加入过去 3 帧局部观测；仅在目标队友当前可见且双方存活时预测其下一原子动作。来自 8 个检查点的事件按评测种子 0–39 训练、40–49 测试，随机采样训练 **40,000 个事件**、测试 **12,000 个事件**。当前观测准确率 **69.95%**，加 3 帧历史为 **65.70%**；测试集中 7,804 个攻击事件上的准确率分别为 **80.39%** 与 **73.45%**。20 条有向观察者→伙伴关系中，仅 4 条历史模型更好。
- 解释边界：这个负结果只涉及单种子、浅层预测器和**局内** 3 帧历史；尚未测试 ETM 核心的跨对局、跨训练阶段持续更新，也未测试该预测是否改善协作。不能据此断言 ETM 无效，但当前设置未提供历史预测增益门槛。

## 跨对局历史门槛

- 对每个检查点、每条观察者→伙伴关系，只用先前 10 局中**观察者自己的局部观测**汇总目标伙伴的可见频率、相对位置、血量和相对运动。查询对局 10–39 用于训练，40–49 留出测试；每次随机采样训练 40,000 个、测试 12,000 个伙伴动作事件。目标伙伴动作只作预测标签，不进入历史特征。另设“另一伙伴的历史”和“10 万步早期历史固定不更新”两个对照。
- 预测器初始化种子 0 / 1 / 2 的总动作准确率分别为：当前局面 **66.14 / 66.52 / 66.33%**；对应伙伴近期历史 **67.75 / 68.94 / 66.35%**；错误伙伴历史 **66.30 / 67.14 / 66.03%**；冻结早期伙伴历史 **67.26 / 67.77 / 65.30%**。近期历史相对当前局面的提升分别为 **1.61 / 2.42 / 0.02 个百分点**，不稳定。
- 种子 0 的 6,847 个留出攻击事件中，当前、近期、错误伙伴、冻结早期历史的准确率依次为 **80.18 / 83.19 / 82.50 / 83.60%**；近期历史**未优于**冻结早期历史。种子 1 同样如此；种子 2 则近期历史低于当前局面。
- 判断：跨对局观察历史存在**弱的伙伴预测信号**，但“动态更新优于旧认知”尚未稳健成立；加之团队胜率剧烈跳变、终点已饱和，这条 `2s3z` 线路不宜直接升为主实验。此诊断使用训练后的静态检查点，仅作离线测试，不构造连续在线学习过程，也不等于 ETM 闭环实验。
