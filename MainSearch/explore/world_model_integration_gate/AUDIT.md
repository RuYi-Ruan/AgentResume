# 代理实验审计

本目录实验真实执行，但不能视为时序世界模型验证。

实际完成内容：

- 540 次三人 Overcooked rollout，共 64,800 个环境步；
- 1,569 参数的高层出汤数回归器；
- 5 个网络初始化，每个进行 250 次小数据全批量更新；
- 完整运行命令墙钟时间约 52 秒。

不具备的内容：

- 没有学习 `state_t, action_t -> state_t+1`；
- 没有时序隐状态；
- 没有递归多步开放环预测；
- 没有基于想象轨迹的滚动规划；
- ETM 概率由伙伴真实角色加噪生成，存在标签泄漏。

因此，该实验只保留为奖励预测代理与代码开发记录。后续真正的世界模型实验必须使用仅由过去可观察历史形成的 ETM，并在未见测试轨迹上报告状态转移误差、奖励误差、多步开放环误差以及想象决策后的真实环境收益。
