# Gate 3：ETM 到协作决策的受控接口

目标：检验更准确的伙伴认知是否能转化为更多出汤，而不直接进入完整端到端主实验。

流程：

1. 三名伙伴继续沿 Gate 0 路径在线学习；
2. 每局先观察若干窗口，六条定向 ETM 分别预测两名伙伴的行为；
3. 将预测转换为伙伴分工估计，再由预先固定的经验收益表选择补位角色；
4. 三名智能体轮流作为决策者，比较动态、冻结、旧分布、无干预和真实伙伴信息上界。

规则低层执行器和角色转换仅用于开发阶段隔离机制，不作为论文主实验实现。

当前状态：修正版 5 种子实验已完成。动态 ETM 优于冻结认知，但硬角色切换整体低于无干预策略，Gate 3 暂未通过。
