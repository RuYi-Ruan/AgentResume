# 四人 RWARE 探索门槛

目标：先判断原生 `rware-tiny-4ag-v2` 能否提供可持续学习、且队友行为会影响收益的基础，再考虑 ETM。探索结果不是正式主实验。

1. 环境门槛：本机隔离安装 RWARE 2.0.0；固定 10 个种子分别跑 500 步随机动作与停留动作，记录每局配送数、奖励和耗时。只验证 API 与得分分布，不据此判断可学习性。
2. 学习门槛：先以 EPyMARL 参考 QMIX 做短程运行成本检查；之后用单种子 10 万步开发试验判断有无可见学习信号，固定每 2 万步评测 20 局并保存模型。若有学习信号，再预定多种子预算（至少 3 个种子）；若无，则先审查训练配置与任务难度，不把单种子短跑判为环境不适合。主指标为每局成功配送数，记录完整曲线，不能用切换 checkpoint 代替伙伴在同一次训练中的能力提升。
3. ETM 前置门槛：伙伴身份与动作必须对观察者可区分；当前观察加历史若不能改善对伙伴下一步行为的预测，或无 ETM 策略已经足以做出决策，就不接入复杂世界模型。

RWARE 原始任务奖励稀疏；若短程随机策略为 0 配送，只能说明随机探索困难，不能直接否定环境。
