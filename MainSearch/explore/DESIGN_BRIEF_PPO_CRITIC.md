## 四、根因假设

V2 的观测是 **7×7×30 的局部视野（1470 维）**；要预测价值必须知道**锅里有几份料、煮到什么程度、其他两位伙伴手上拿着什么、身上朝向**——这些在局部视野里常常看不到。因此 V(o) 是部分可观测下的困难目标，critic 学不出来 → 优势噪声 → actor 漂移。

## 五、需要你定夺的问题

1. **是否采用"非对称 / 特权 critic"（CTDE 标准做法）？** 具体设想：critic 额外看一个**紧凑全局状态**（锅的料数+计时、三位智能体的位置/朝向/手持、菜谱指示、静态网格的低维编码，合计约 700–800 维），**actor 完全不变**（仍是 1470 维局部视野 + 将来的 z），且**critic 永不见 z**。各实验臂的 critic 结构完全相同，故不引入臂间差异；被比较的策略本身也不变。请确认这不会破坏你的"干净协议"，并指出实现上的坑（例如是否必须同时保证 actor 侧不看全局信息、是否需要把 critic 的输入也固定 seed）。
2. **若不采用**，按性价比排序应优先做哪几项：(a) γ 0.99 → 0.97 缩短有效视野；(b) 收益/价值归一化（running mean-std）；(c) 更长的 critic 预热（例如 300–500 次更新）与更大 critic；(d) 训练期给"取食材/靠近锅"小额密集奖励（之前排在最后，但现在看 critic 缺光滑目标）；(e) 直接用全可见观测训练 critic（19×13×30=7410 维，仅 critic 用）。
3. **如果 critic 问题短期修不好，研究设计上能否接受"永久小型锚点"？** 即 λ、β 衰减到一个下限（例如 0.1）而不是 0。好处：稳定、各臂一致、可写进协议；代价：PPO 难以超越 BC（目前 21 段没有任何超越迹象）。但我们的研究问题要的是"伙伴能力随经验演化"（P2），不一定要达到 SOTA；请判断"锚点固定 + 有限演化"是否仍能满足 P2，还是必须换学习器。
4. **步数与判据**：修好 critic 后，你希望看到的 3M 门槛是什么（例如：采样份/局 ≥1.5 且最后 5 段单调/正趋势）？以及是否仍按你上轮的次序（3M → 10M → Oracle Gate），还是先在 1M 内确认"critic 解释方差 > 0.3"再继续？

# 第二轮：CTDE critic 已实现，结论与新的卡点

**结论先行：你的判断被实验证实——critic 修好后，灾难性遗忘基本止住、EV 从 0 升到 0.75–0.9；但 PPO 仍然没有超过 BC，且锚点一旦完全归零就开始退化。**

## 已实现的改动

1. **紧凑 CTDE 状态（35 维）**，替代原来的 754 维网格：每智能体 7 维（x/宽、y/高、朝向/4、空手/持盘/持菜/持料 四标志）×3 + 每锅 4 维（料数/3、火候/20、已煮、空闲）+ 食材类型 one-hot + 菜谱 one-hot + 进度 t/T。
2. **value normalization**：running 均值/方差（count/mean/var 随 runner state 传递）归一化奖励后做 GAE。
3. actor / critic 两个 encoder 完全独立（不共享早期特征）；critic 只用 s_t。
4. 新增诊断：EV、优势标准差、corr(A, 回报)、value loss、近似 KL、clip 比例。

- **1M**：EV 持续 0.83–0.89 ✅；熵稳定 0.18–0.20，无"熵升+收益降" ✅；但采样段均值 **0.96**（BC 1.13）❌ —— 未达你给的 R_1M ≥ R_BC。

## 我的读解与正在做的实验

锚点（reference-KL / 演示正则）在的话策略就停在 BC 附近，说明**PPO 自身的梯度没有把策略推向更好的解**；而 EV≈0.9 说明优势并非噪声。二者结合指向一个更朴素的解释：**actor 被压得太保守，根本没有机会学**——LR 1e-4、clip 0.1、rollout 64（而完成一份汤要 150–300 步）、锚点初值 1.0，3M 步里有效梯度步只有数千次。

因此正在跑：**放开 actor**（LR 2.5e-4、clip 0.2、rollout 128、4 epoch）+ **锚点衰减到 0.1 的永久地板**（你已确认永久小锚点合规），其余不变，3M 步看是否出现 > BC 的上升。
